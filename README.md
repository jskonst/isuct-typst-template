# Шаблон документов ИГХТУ (ГОСТ 7.32) на Typst

Титульный лист и лист «Задание» кафедры информационных технологий и цифровой экономики ИГХТУ, дальше — текст по ГОСТ 7.32‑2017. Ядро — пакет [modern-g7-32](https://github.com/typst-g7-32/modern-g7-32) (GPL-3.0-only). Бланки подогнаны по образцам Word из каталога `reference/`.

Готовый пример можно открыть без сборки:

- [results/example.pdf](results/example.pdf) — выпускная работа, 16 страниц;
- [results/pages/](results/pages/) — те же страницы в PNG;
- [results/comparison/](results/comparison/) — бланк Word рядом с Typst и прежний макет рядом с текущим.

Пример собирает два разных бланка, как в исходных файлах Word. Титульный лист — П. А. Денисова, тема про транспортное страхование. Задание — О. Р. Лифанов, тема про учёт педагогической нагрузки. Главы написаны по теме задания и прямо говорят, почему на титуле другой студент.

## Сборка из командной строки

Нужен [Typst 0.14](https://github.com/typst/typst/releases) (проверялось на 0.14.2). Шрифт бланка — Times New Roman; если его нет, подставляется Liberation Serif из системы или из каталога `fonts/` (латиница совпадает по метрикам, кириллица может чуть сдвинуть переносы). Схема DOT в главе 3 рисуется пакетом diagraph: это WASM-модуль, отдельная программа `dot` не нужна.

```bash
# диплом: титул, задание, главы, сноски, источники
typst compile --root . examples/isit-diploma/main.typ results/example.pdf

# то же самое: main.typ в корне подключает пример
typst compile --root . main.typ results/example.pdf

# короткий отчёт без бланка кафедры
typst compile --root . template/main.typ results/generic-report.pdf
```

Импорты относительные (`../../src/export.typ` и рядом). Абсолютных путей вида `/src/...` в проекте нет, локальных пакетов `@local` тоже. Ключ `--root .` в этих командах оставлен: с относительными импортами сборка от него не зависит.

Скрипт делает то же самое и, если есть `pdftoppm`, обновляет PNG страниц:

```bash
./build.sh
```

Пакеты Fletcher, CeTZ и diagraph Typst скачает сам в кэш (`~/.cache/typst`). Сеть нужна только при первой сборке.

## Сборка в Docker

Образ ставит Typst 0.14.2, Times New Roman, Liberation Serif и Graphviz, затем один раз компилирует пример, чтобы прогреть кэш пакетов.

```bash
docker build -t isuct-gost .
docker run --rm -v "$PWD":/work -w /work isuct-gost \
  compile --root . examples/isit-diploma/main.typ results/example.pdf
```

Без аргументов образ выполняет ту же команду `compile` для примера. В образе есть `zip`, поэтому там же собирается архив для typst.app:

```bash
docker run --rm --entrypoint bash -v "$PWD":/work -w /work isuct-gost \
  ./scripts/make-typst-app-zip.sh
```

## Проект на typst.app

Веб-приложение не видит шрифты и программы вашего компьютера. Архив `dist/isuct-typst-app.zip` содержит только файлы проекта: точку входа, шаблон, пример, шрифт и лицензию. Его же собирает скрипт:

```bash
./scripts/make-typst-app-zip.sh
```

Как загрузить проект:

1. Откройте [typst.app](https://typst.app) и создайте пустой проект (кнопка нового проекта на панели, не шаблон из Universe).
2. Скачайте `dist/isuct-typst-app.zip` из репозитория или соберите его командой выше.
3. Распакуйте архив у себя на диске. В корень должны лечь `main.typ`, каталоги `src`, `examples`, `fonts`, `template` и файл `LICENSE`.
4. В редакторе откройте панель файлов и перетащите туда это содержимое. Сам zip веб-приложение не распаковывает: если бросить архив как один файл, сборка его не увидит. Папки нужно сохранить папками, а не россыпью файлов в корне.
5. Откройте `main.typ` и включите его предпросмотр. Это выпускная работа: титул, задание и главы. Короткий отчёт без бланка кафедры — `template/main.typ`, его можно открыть отдельно.

Шрифт. В `fonts/` лежит Liberation Serif (лицензия SIL OFL, текст в `fonts/OFL.txt`): обычное, жирное, курсив и жирный курсив. typst.app сам находит `.ttf` и `.otf` в проекте, в том числе во вложенной папке, и ставит их выше шрифтов сервера. В шаблоне порядок семейств такой: сначала Times New Roman, затем Liberation Serif. Times New Roman на сервере нет, поэтому подставится Liberation Serif. Латиница у него метрически совпадает с Times, кириллица может чуть сдвинуть переносы. Свои файлы Times New Roman в репозиторий не входят (это шрифт Microsoft). Если они у вас есть, загрузите `.ttf` в `fonts/`: семейство стоит первым в списке и перекроет Liberation Serif.

Схемы Fletcher, CeTZ и diagraph подключаются как `@preview/...` из Typst Universe. В веб-приложении они доступны без локальной установки. diagraph рисует DOT своим WASM-модулем и не вызывает системную программу `dot`. Подписи внутри этой схемы просят семейство Times New Roman. Если его в проекте нет, для подписей схемы Typst берёт встроенный шрифт, а весь остальной текст остаётся Liberation Serif.

Ограничение Mermaid. Компилятор Typst, и локальный, и typst.app, не исполняет JavaScript, поэтому текст `examples/isit-diploma/diagrams/sequence.mmd` сам в рисунок не превращается. В проект уже положен готовый `sequence.svg`, и пример ссылается на него. Чтобы перерисовать SVG, нужен локальный `mmdc` и `./scripts/render-mermaid.sh`. Этого скрипта в архиве для typst.app нет.

## Как заполнить титульный лист и задание

Все поля примера — в `examples/isit-diploma/main.typ`. Функция `gost.with(...)` принимает и параметры ГОСТ, и поля бланка ИГХТУ (их забирает `examples/isit-diploma/isit-diploma.typ`).

Титульный лист:

| Поле | Куда попадает |
| --- | --- |
| `department` | название кафедры под шапкой, строчными, шаблон набирает его жирным 16 пт |
| `work-type-lines` | «ВЫПУСКНАЯ КВАЛИФИКАЦИОННАЯ РАБОТА» / «БАКАЛАВРА», 20 пт |
| `topic-lines` | тема в кавычках, три строки; шаблон переводит их в верхний регистр |
| `student.short-name` | строка «Автор:», например `П.А. Денисова` |
| `supervisor` | `position` и `name` в строке «Руководитель:» |
| `department-head` | строка «Зав. кафедрой:» |
| `city`, `year` | «г. Иваново, 2026 г.» |

Шапка министерства задана списком `default-letterhead` в `isit-diploma.typ`. Свой список передают параметром `letterhead`.

Задание собирают словарём `diploma-assignment(...)` и передают как `assignment`:

- `student.full-name` и `student.dative-name` — «Лифанов Олег Роланович» и «Лифанову Олегу Ролановичу»;
- `topic`, `order.number`, `order.date` — тема и строка приказа;
- `source-data` — пункт 2;
- `contents` — список словарей `(lead:, text:)`. У введения в бланке Word стояла лишняя точка (`. Введение:`); в шаблоне её нет, двоеточие после названия остаётся. У главы 5 нет точки между двумя руководствами: так напечатан бланк;
- `special-questions` — пункт 4, в образце пустой;
- `supervisor.name`, `supervisor.full-name`, `supervisor.position`;
- `approved-by` — блок «УТВЕРЖДАЮ» (должность, фамилия, дата);
- `consultants` — строки таблицы консультантов;
- `issue-date`, `deadline`;
- `calendar-plan` — список `(name:, dates:)`. Даты оставлены как в Word, включая `16.02-2026` и разные тире.

На листе задания кафедра, факультет, уровень, направление и профиль берутся из `assignment-department`, `faculty`, `education-level`, `program`, `profile`. Кафедра на титуле — строчными (`department`), на задании — с заглавной (`assignment-department`).

Короткий отчёт без этих бланков — `template/main.typ`: обычный титул ГОСТ через `gost.with`.

## Заголовки

Разделы и подразделы основного текста стоят слева, с тем же абзацным отступом 1,25 см, что и первая строка абзаца, и без жирного. После номера — точка: «1. ФОРМИРОВАНИЕ ТРЕБОВАНИЙ», «1.1. Участники учёта». Название раздела (уровень 1) шаблон печатает прописными, даже если в исходнике оно обычным регистром. В содержании у номеров та же точка, названия разделов тоже прописные, вложенные пункты остаются как в исходнике.

Структурные элементы без номера — СОДЕРЖАНИЕ, ВВЕДЕНИЕ, ЗАКЛЮЧЕНИЕ, СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ, ПРИМЕЧАНИЯ — по центру строки, прописными, без точки и без жирного. Так требует ГОСТ 7.32‑2017, п. 6.2.1: заголовок структурного элемента располагают в середине строки. Нумерованный раздел при этом остаётся слева: для него ГОСТ задаёт абзацный отступ (п. 6.5.1). Точку после номера просили отдельно: в самом ГОСТ 7.32‑2017 после номера раздела точка не ставится.

## Ссылки на таблицы, рисунки и формулы

Подключение в начале документа, после `#show: gost.with(...)`:

```typst
#import "numbering.typ": gost-numbering, Ref
#show: gost-numbering
```

`#include` не выносит `set`/`show` наружу, поэтому нумерация — это функция-обёртка, а не отдельный include. `#Ref` из того же модуля виден только там, где его импортировали: в подключаемой главе нужен свой `#import "../numbering.typ": Ref`.

Дальше в главе:

```typst
#figure(
  table(...),
  caption: [Роли пользователей приложения],
) <tab-roles>

$ H = sum_(i=1)^n k_i h_i , $ <eq-hours>
```

`@tab-roles` в середине предложения даёт «табл. 1.1», `@fig-arch` — «рис. 2.1». Это форма по умолчанию, со строчной буквы. В начале предложения ту же ссылку пишут через `#Ref`: получается «Табл. 1.1» или «Рис. 2.1». Формула не меняется: и `@eq-hours`, и `#Ref(<eq-hours>)` дают «(1.1)».

```typst
#Ref(<tab-roles>) перечисляет роли.
См. @tab-roles — та же таблица.
#Ref(<fig-arch>) показывает контур.
Подробности — на @fig-arch.
См. @eq-hours.
```

Подпись самого объекта остаётся полной: «Таблица 1.1 — …», «Рисунок 2.1 — …». Слово в подписи и слово в ссылке задаются раздельно. Номер — глава и номер объекта в этой главе. Счётчики рисунков, таблиц и формул сбрасываются на каждом заголовке первого уровня. Номер формулы стоит справа в скобках.

Своё дополнение можно передать в `ref`, если нужна другая строчная или прописная форма:

```typst
#ref(<fig-arch>, supplement: [рисунок])
```

Тогда ссылка читается как «рисунок 2.1». `#Ref` этот аргумент не принимает: по виду объекта он сам ставит «Рис.» или «Табл.». Склонения шаблон не делает.

## Концевые сноски

```typst
#import "../endnotes.typ": endnote
... слово#endnote[Текст сноски.]
```

Номер в тексте — верхний индекс. Тексты собираются в разделе «Примечания» вызовом `#endnotes()` перед `#bibliography`. Это не постраничные сноски: порядок сквозной по всему документу.

## Рисунки из текста

В примере четыре способа. Три первых живут в `.typ`, четвёртый — отдельный текстовый источник плюс шаг сборки.

| Способ | Где смотреть | Что нужно кроме Typst |
| --- | --- | --- |
| [Fletcher](https://typst.app/universe/package/fletcher) 0.5.8 | глава 2, `03-koncepciya.typ` | ничего, пакет качается в кэш |
| [CeTZ](https://typst.app/universe/package/cetz) 0.5.2 | глава 2, тот же файл | ничего |
| [diagraph](https://typst.app/universe/package/diagraph) 0.3.7, язык DOT | глава 3, `04-tz.typ` | ничего: пакет сам содержит WASM-модуль Graphviz |
| Mermaid | `diagrams/sequence.mmd` и SVG рядом | компилятор Typst Mermaid не исполняет: нет JavaScript |

Fletcher короче для блок-схем из узлов и стрелок. CeTZ — холст с координатами, когда важны размеры. DOT удобен, если схема уже написана для Graphviz; `raw-render` вызывает WASM-модуль diagraph, а не системную программу `dot`. Русские подписи в DOT задают `fontname="Times New Roman"`.

Mermaid оставлен как текст `examples/isit-diploma/diagrams/sequence.mmd`. Рядом лежит готовый `sequence.svg`, поэтому пример собирается без Node.js. Чтобы перерисовать SVG:

```bash
npm install -g @mermaid-js/mermaid-cli
./scripts/render-mermaid.sh
```

Если `mmdc` не найден, скрипт ничего не затирает и оставляет SVG из репозитория.

## Чем бланк отличается от Word

Поля, кегль, шаг строк, подчёркивания и таблицы сняты с `reference/titul.docx` (титул) и `reference/zadanie.docx` (задание). Рядом — `results/comparison/`.

Что совпадает близко: шапка прописными 14 пт, кафедра 16 пт, вид работы 20 пт, тема двойным интервалом, линии подписей, город внизу; на задании — жирные подписи и подчёркнутые значения, блок «УТВЕРЖДАЮ», таблицы консультантов и календарного плана, разрыв страницы перед пунктом 6.

Что осталось иначе:

1. В одном документе титул — страница 1 без номера. Первая страница задания (страница 2) тоже без номера внизу, но в счёт входит: следующая страница задания уже с номером 3. Отдельный файл Word нумерует задание как 1 и 2.
2. Строки темы и содержания задания переносятся на слово позже, чем в Word: у этой сборки Times New Roman кириллица чуть уже.
3. По вертикали титул уезжает вниз не больше чем на несколько пунктов.
4. Кавычки темы набраны тем же кеглем 16 пт, что и слова. В Word кавычки — 14 пт.
5. Жёлтая заливка Word не перенесена.
6. Номер страницы основного текста — 12 пт, как на листе задания. У чистого отчёта ГОСТ колонтитул задаёт ядро шаблона.
7. Ссылка в тексте — «табл. 1.1» / «рис. 2.1», в начале предложения — «Табл.» / «Рис.». Подпись объекта — «Таблица 1.1» / «Рисунок 2.1». Склонения нет.

## Состав репозитория

- `main.typ` — точка входа: выпускная работа.
- `src/` — ядро ГОСТ 7.32 (шрифт Times New Roman с запасным Liberation Serif, город на титуле, заголовок «Примечания»).
- `examples/isit-diploma/` — бланки, нумерация, сноски, главы, библиография, схемы.
- `template/main.typ` — короткий отчёт без бланка кафедры.
- `fonts/` — Liberation Serif (OFL) для typst.app.
- `dist/isuct-typst-app.zip` — тот же проект, упакованный для загрузки в веб-приложение.
- `reference/` — исходные docx.
- `results/` — собранный PDF и картинки страниц.
